Scroll Observer

Synchronise the arm to the scroll position, in both directions, with one bound value.

  • Two-way scrub, never a one-shot trigger
  • Frame-rate independent damping
  • One observer per act, one writer per frame

Runs like clockwork

One requestAnimationFrame owns the clock. anime.js updates values, three.js draws them — never the other way round.

  • Single owned RAF loop
  • anime.js engine driven manually
  • dt clamped across tab switches
